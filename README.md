# Auto-LaTeX Equations for ONLYOFFICE

ONLYOFFICE plugin (document editor) that converts LaTeX written in text (`$...$` and `$$...$$`) into actual mathematical equations.

## Features
- **Convert All Equations** button: processes the entire document.
- **Automatic Conversion** option: converts content you paste (or type) as long as the plugin panel is open.
- False-positive prevention rules: `5$ and 6$` will not be converted.

## Requirements
ONLYOFFICE Docs / Desktop Editors **8.2 or later** (`AddMathEquation` method).

## Installation
1. Download `auto-latex-equations.plugin` from the **Releases** page.
2. Desktop Editors: *Plugins* → *Manage Plugins* → *Add Plugin*.
3. Open **Auto-LaTeX Equations** from the *Plugins* tab.
